# overflow-follow-react

Overflow Follow 的 React 组件与 hook。完整文档与示例请查看 [Overflow Follow](https://github.com/ss548/overflow-follow)。

The React component and hook for Overflow Follow. See the [English documentation](https://github.com/ss548/overflow-follow/blob/main/README.en-US.md) for the complete guide and examples.

```tsx
import { OverflowFollow } from 'overflow-follow-react';
import 'overflow-follow-react/style.css';

export function Example() {
  return <OverflowFollow text="A very long single-line value" />;
}
```
