# overflow-follow-vue

Overflow Follow 的 Vue 3 组件与 composable。完整文档与示例请查看 [Overflow Follow](https://github.com/ss548/overflow-follow)。

The Vue 3 component and composable for Overflow Follow. See the [English documentation](https://github.com/ss548/overflow-follow/blob/main/README.en-US.md) for the complete guide and examples.

```vue
<script setup lang="ts">
import { OverflowFollow } from 'overflow-follow-vue';
import 'overflow-follow-vue/style.css';
</script>

<template>
  <OverflowFollow text="一段非常长的单行内容 / A very long single-line value" />
</template>
```
